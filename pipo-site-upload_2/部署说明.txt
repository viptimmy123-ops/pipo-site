皮果英语 · 部署说明（GitHub → Cloudflare Workers）

仓库根目录（第一层）必须正好是：
  data/（11 个文件）  pages/（36 个文件）  brand/（20 个文件）  _headers  favicon.svg  index.html  wrangler.jsonc  .assetsignore  部署说明.txt

更新步骤：
1. 解压本压缩包，打开解压出来的文件夹，全选里面的所有文件和文件夹（data、pages 两个文件夹也要选）。
2. GitHub 仓库 pipo-site → Add file → Upload files → 把选中的内容直接拖进去（不要拖外层文件夹）。
3. 同名文件会被覆盖，点 Commit changes。
4. Cloudflare 自动部署，约 1 分钟后打开 https://pipo.typeoai.cn/
注意：.assetsignore 是隐藏文件，Mac 上按 Cmd+Shift+. 显示后再一起选中；漏传也不影响访问。

提示：pages/ 里旧的 light-d.json、light-m.json、dark-d.json、dark-m.json 已不再使用，可以在 GitHub 上删掉，不删也不影响。
